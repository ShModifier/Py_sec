# Py_sec

### 项目简介

Py_sec 是一个基于 Python 实现的代码漏洞检测系统，结合静态分析与 AI 语义分析技术，对 Python 源代码进行安全检测。



### 主要功能

- 污点传播分析（变量赋值、函数传参、字符串拼接）
- 常见漏洞规则检测（SQL注入、命令执行、XSS、路径遍历等）
- AI语义二次分析（降低误报）
- 可视化图形界面操作


###  快速开始（Quick Start）

#### 运行环境要求

为保证系统正常运行，需满足以下基本环境要求：

操作系统：Windows 10及以上版本 / Linux发行版

Python版本：Python 3.9及以上

依赖环境：系统所需第三方库已在 requirements.txt 中给出


####  1. 安装依赖
在首次运行前，可通过以下命令完成依赖安装：

```python
pip install -r requirements.txt
```

####  2. 启动系统
python main.py

####  3. 数据配置
在首页中选择使用的 api 供应商信息并填写自己的 apikey ，使用前需要保存，下次打开文件时会自动加载上一次的选择。

当前系统仅支持deepseek、Qwen、openAI

####  4. 导入文件

点击“选择文件”，选择 .py 源代码文件。系统将自动加载文件路径并显示在表格中。同一文件不可重复添加，右键可以删除文件。

####  4. 选择检测模式

可选模式：

- 静态分析模式（纯静态规则匹配）
- 
- AI分析模式（完整文件直接构造进prompt，检查大文件时token消耗较大）
- 
- AI辅助增强分析模式（静态分析基础上将危险源码切片构造prompt，适用大文件少漏洞情况）

####  5. 开始检测

点击“开始扫描”，系统将自动执行分析流程，等待结果输出即可

系统采用多线程架构方式，扫描过程以当前整个表格为单位进行。扫描过程中会显示当前正在操作的文件，对检查完毕的文件可以立即查看结果，未检查到的文件可以进行删除操作


####  6. 查看检测结果

输出内容包括：

- 漏洞类型

- 位置（文件 + 行号）

- 风险等级

- AI复核结果（如启用）

##  注意事项

推荐使用「静态 + AI分析」组合模式,大文件分析可能耗时较长
